# UML 类图

> 本案例用 md 内嵌 mermaid 实现

其实我们说，类图就包含两个东西，类与类的关系

## 类

> 类是具有相似结构、行为和关系的一组对象的描述符，是面向对象系统中最重要的构造块。

例如：

```mermaid
classDiagram
    class 动物 {
        + 有生命
        + 新陈代谢(in O2 :氧气 in water :水)
        + 繁殖()
    }
```

你会发现在这个例子中，有三个格子，分别是

- 类名称（接口要斜体）
- 类的特性（类的字段或属性）
- 类的操作（类的方法和行为）

它们前面的符号有三类：

- `+`表示 public
- `-`表示 private
- `#`表示 protected

## 类的关系

### 1.依赖关系（虚箭线）

> 所谓依赖关系，就是构造这个类的时候，需要依赖其他的类，比如：动物依赖水和氧气。如下图所以：

```mermaid
classDiagram
    class 动物 {
        + 有生命
        + 新陈代谢(in O2 :氧气 in water :水)
        + 繁殖()
    }
    class 氧气 {

    }
    class 水 {

    }
    动物 ..> 氧气 : 依赖关系
    动物 ..> 水 : 依赖关系
```

mermaid 没法实现引出来一个分支来画，但是两个可以都打 tag

### 2.继承、泛化关系（实线空心三角箭头）

```mermaid
classDiagram
    class 动物 {
        + 有生命
        + 新陈代谢(in O2 :氧气 in water :水)
        + 繁殖()
    }
    class 鸟 {
        + 羽毛
        + 有角质没有牙齿
        + 下蛋()
    }
    class 企鹅 {
        +下蛋()
    }
    class 鸭 {
        +下蛋()
    }
    class 大雁 {
        +下蛋()
        +飞()
    }
    class 唐老鸭 {
        +讲话()
    }
    唐老鸭 --|> 鸭 : 继承关系
    鸭 --|> 鸟
    企鹅 --|> 鸟
    大雁 --|> 鸟
    鸟 --|> 动物
```

### 3.实现关系（虚线空心三角箭头）

```mermaid
classDiagram
    class 大雁 {
        + 下蛋()
        + 飞()
    }
    class 飞翔 {
        <>
        + 飞()
    }
    大雁 ..|> 飞翔 : 实现接口
```

mermaid 貌似不能实现 `<<interface>>` 这种东西，只能照着 class 声明接口的方法来（就是往里面塞个`<>`），或者说用 Ixxxx 标识接口

```mermaid
classDiagram
    class 大雁 {
        + 下蛋()
        + 飞()
    }
    class 飞翔 {
        <<interface>>
        + 飞()
    }
    大雁 ..|> 飞翔 : 实现接口
```

### 4.关联关系（实箭线）

> 所谓关联关系，就是这个类有一个属性是其他类。

```mermaid
classDiagram
    class 企鹅 {
        + 下蛋()
    }
    class 气候  {

    }
    企鹅-->气候 : 关联关系
```

### 5.聚合关系（实线空心菱形）

> 聚合关系是关联关系的一种，是强的关联关系 ；
> 特点： 部分对象的生命周期并不由整体对象来管理。也就是说，当整体对象已经不存在的时候，部分的对象还是可能继续存在的。比如：一只大雁脱离了雁群，依然是可以继续存活的。

uml 类图里面是这样表示的
[整体] ◇—————→ [部分]

```mermaid
classDiagram
     class 大雁 {
        + 下蛋()
        + 飞()
    }
    class 雁群 {
        + V形飞行()
        + 一形飞行()
    }
    雁群 o-- 大雁 : 聚合关系
```

### 6.组合关系（实线实心菱形）

```mermaid
classDiagram
    class 鸟 {
        + 羽毛
        + 有角质没有牙齿
        + 下蛋()
    }
    class 翅膀 {

    }
    鸟 *-- 翅膀 : 组合关系
```

## 补充

大概就是这样了
但是关于 mermaid 的关系语法还有些要说的

比如我们要表示数量上的关系
符号 | 含义
-|-
"1"|恰好一个
"0..1"|零个或一个
"\*"或"0..\*"|零个或多个
"1..\*"|一个或多个
"n"|恰好 n 个
"m..n"|m 到 n 个
"5..\*"|至少五个

```mermaid
classDiagram
    class 鸟 {
        + 羽毛
        + 有角质没有牙齿
        + 下蛋()
    }
    class 翅膀 {

    }
    鸟 "1" *-- "2" 翅膀 : 组合关系
```

```mermaid
classDiagram
    class 大雁 {
        + 下蛋()
        + 飞()
    }
    class 雁群 {
        + V形飞行()
        + 一形飞行()
    }
    雁群 "1" o-- "2..*" 大雁 : 聚合关系
```

```mermaid
classDiagram
    class 图书馆 {
        # 安静
        + 出阅书籍()
    }
    class 书籍 {
        + 可借阅
        + 阅读()
    }
    图书馆 "1" o-- "0..*" 书籍 : 聚合关系
```
